# NexaShop Frontend

A modern e-commerce admin dashboard built with Angular.

## Tech Stack
- Angular 19 (Standalone Components)
- TypeScript
- Angular Signals
- Angular Material
- HTTP Interceptors for JWT

## Features
- Authentication (Login/Register with JWT)
- Products Management (CRUD, Search, Pagination)
- Customer Management
- Analytics Dashboard
- Shared Layout with Navbar and Sidebar

## Setup
```bash
npm install
ng serve
```

Open http://localhost:4200
